# Automated-Log-Parsing-Incident-Response
Python script for streamlining troubleshooting by automating error detection, alerting, and incident management for cloud infrastructure.
A lightweight CLI and API-integrated tool that: 

Automate Parsing: 
  Regex-based error detection with configurable patterns (e.g., ERROR, CRITICAL). 
  Extensible to handle multi-line exceptions and custom log formats. 
Real-Time Alerting: 
  Integrated with Splunk for centralized logging. 
  Microsoft Teams webhook notifications for immediate team awareness. 
Scalability: 
  Lightweight Flask API for health checks and future extensions. 
  Thread-safe design for high-volume log processing.
